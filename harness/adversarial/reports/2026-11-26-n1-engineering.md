The slice is sound: the Dart engine is pure `double` (binary64) end-to-end — `clearfile/lib/tax/calculator.dart` types every intermediate `double`, `tax_year.dart:154-301` stores all parameters as `double` — so the annex's f64-first rule (ADR-017, `DECISIONS.md:530-533`) genuinely matches the reference. `tools/`-gitignored toolchain, std-only crate, GPL headers, and "17/17 is N1's exit, not session-1's" all line up with `ROADMAP.md:563-571` and `STATE.md:299-315`. The findings are about under-specified mechanics, not direction.

## Conditions

1. **Define the comparator exactly; strike "cent-based."** The oracle (`verify_golden_fixtures.py:317-331`) does NOT round to cents: it compares field-set = the fixture's `expected` keys only, `deductionMethodUsed` by exact string, everything else `|computed − pinned|` failing only when `delta > tolerance` (so delta == tolerance passes), per-fixture `tolerance` defaulting to 0.005 (16 fixtures; fixture 01 uses 0.505). Cent-quantizing both sides *masks* deltas the oracle fails (pinned 100.00, computed 99.9951 passes rounded, fails raw). Verify: harness doc-comment states those five rules verbatim, plus a unit test with deltas at exactly-tolerance (pass), tolerance+ε (fail).
2. **Fail closed on non-finite values.** `web_parity_test.mjs:93` uses `!(delta <= tolerance)` and the Decimal oracle crashes on NaN — both fail-closed; Rust's `delta > tolerance` returns **false** for NaN and would silently pass. Verify: a test with a NaN/∞ computed value fails the harness.
3. **Honest-subset = a committed per-fixture skip map, not a module list.** The field census (all 17 files) shows every fixture pins `agi`/`taxableIncome`/`ordinaryTax`/`niit` — the whole pipeline runs in every fixture — so "green on the subset" is only mechanically definable per-fixture, keyed to input **features** (preferential / senior / itemized / dependents / SLI). Shape: `core/tests/` map of all 17 filenames → `run | deferred{reason, waiting-on-feature}`, plus a guard test asserting map keys == the directory's `*.json` set exactly (a new/renamed fixture fails loudly, no silent drift). Verify: `cargo test -- --list` enumerates 17; session log records "N/17 green, M deferred (names)"; deleting the map entry for a present fixture fails the guard.
4. **Restate the slice: the compute path is one pipeline.** The proposal omits SLI and SALT, but SLI feeds AGI and SALT feeds the deduction choice in every fixture (`calculator.dart:31-76`); fixtures 10/11 additionally pin `saltCap`/`saltAllowed`/`deductionMethodUsed`. Verify: the session log's slice statement names SLI + SALT + deduction-choice + payments as included, or the skip map accounts for every fixture that needs them — `calculator.dart` is 325 lines; porting it whole is cheaper than the alternative.
5. **Port the arithmetic-semantics traps explicitly (four rules).** (a) Preserve operation *order* (f64 non-associativity: the `totalIncome` fold, bracket accumulation `calculator.dart:253-263`); (b) keep the CTC cents-normalize **before** the $1,000 ceiling (`calculator.dart:117-122` — load-bearing against f64 dust; the oracle has no such step because Decimal is exact, so do NOT port the oracle's `+999` integer idiom, `verify_golden_fixtures.py:186-189`); (c) Dart round/ceil == Rust `f64::round`/`ceil` (both half-away-from-zero / ceiling); (d) Dart `min`/`max` propagate NaN, Rust's ignore it (unreachable via JSON — note it anyway). Verify: the four points in the harness doc-comment, and fixture 12 (the rounding fixture) is in the session-1 GREEN set.
6. **Deferring the differential/property harness is acceptable at ENTRY only if recorded as debt with a named mechanism.** Annex (a) is N1-exit scope, not session-1 scope — but the deferral must not silently die. Verify: a `DEBT.md` entry (D33 precedent) citing ADR-017 annex (a), naming the mechanism (Dart-side random/edge generator emitting JSON cases a later cargo test consumes) and the lane; N1's exit checklist names the harness.
7. **Fixture-JSON reader: tests-only is right; make it strict, unlike the Dart loader.** `json_codec.dart:6-41` + `tax_return.dart:150-184` default every field (unknown status → `single`, unknown method → `auto`), so the Dart loader cannot detect schema drift; the Rust reader should error on missing/misspelled input fields so drift fails loudly. Verify: a test feeding a fixture with a missing required field fails with a named-field error.
8. **CI step wired with the repo's posture.** `cargo test` in `hygiene.yml`'s suites job (working-directory `core/`, explicit `../fixtures/tax` resolution — STATE quirk 16's analog), any new action SHA-pinned (hygiene.yml:30 precedent), plus a zero-dependency assertion (lockfile has exactly one package, or no `[dependencies]` section) enforcing the licensing annex until cargo-deny lands. Verify: the hygiene.yml diff + a green CI run on the session's pushed tip.
9. **Record the 16→17 count erratum.** `DECISIONS.md:519-520` and `ROADMAP.md:566` say 16; the actual is 17 (D33 QSS, `STATE.md:71-77`). Verify: one correcting sentence in the session log/gate record, `harness_check.sh` still 0.

## Risks register

- **R1:** f64 parse of pinned JSON literals (≤1 ulp error) vs the oracle's exact Decimal could flip a delta sitting within ~1e-12 of the tolerance — not reachable with these pinned values; annex (c)'s Decimal-oracle tiebreaker covers it.
- **R2:** CI uses the runner's preinstalled stable while the sandbox pins a tarball — minor-version skew (new lints/edition behavior); mitigate with a recorded version in the session log.
- **R3:** Later sessions (codecs, envelope) need user-visible strings *in* the core (annex (b)) and a stable value type; session-1's `TaxResult` should reserve that shape now or record it as the codecs session's task — the module split (params / engine / results, no I/O in lib) otherwise anticipates them cleanly.

- The oracle crashes (KeyError) on a fixture pinning a field it doesn't derive (e.g. `marginalRate`, pinned nowhere per D31c) — if session 1 authors fixtures, pin only three-runner-derivable fields.
- The `agi > 0` effective-rate guard (`calculator.dart:155`) must survive the port — fixture 00 pins `effectiveRate`.
