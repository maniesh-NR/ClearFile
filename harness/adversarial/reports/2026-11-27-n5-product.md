## Risks register

- **The author-blind Swift round-count (the named cost, Condition 6):** zero
  local lane (measured — `swift`/`swiftc` both absent), so every compile/link
  error is a blind push→wait→inspect round; the Swift-specific classes are
  new (the SPM C-target header wiring, the dylib link + rpath vs the Linux
  direct-link precedent, the platform pin vs the image SDK). Mitigations:
  headless-first (Condition 6(i)), the honest round record (6(ii)), the
  red-close absorption rule (6(iii)), the N3/N4 datums as calibration.
- **The `-latest` label float:** `macos-latest` is a floating label with a
  documented 1–2 month gradual migration; when it floats (26 → 27), an
  un-echoed lane's verification claim silently drifts — the single most
  likely honesty failure of this lane over time. Mitigation: Condition
  2(a)'s per-run identity echo (`sw_vers` + `swift --version`) so every
  green run is dated with its resolved image.
- **The authored-but-unverified window mode:** the AppKit rendering path is
  unproven (no interactive session); the silent-wrong classes include the
  palette ARGB-uint32 misread into NSColor (the N4 D2 RGBA byte-order
  cousin) and AppKit text-layout surprises. Mitigation: Condition 2(ii)'s
  named non-verification + Advisory 1 (the headless theme dump turns the
  color VALUES CI-proven even though the rendering stays named-unverified).
- **The SPM consumption drift:** a hand-copied header under `apps/macos` would
  fork the ABI contract while the freshness check stays green (it only
  guards `core-ffi/`'s own regeneration). Mitigation: Condition 4's symlink
  + `cmp` assertion.
- **The one-session fatigue:** all rounds + the close bookkeeping in one
  box raises the sloppiness risk precisely where the records matter most.
  Mitigation: Condition 6's four named disciplines + Condition 7's
  mechanical checker gate (0 failures before each backup).
- **The deployment-floor runtime gap:** the floor is build-time-only until an
  owner-side build exists; a future GA on the strength of CI-only
  verification would ship an unverified floor. Mitigation: Condition 2's GA
  clause + Condition 3's honest resolution.
- **The slip's indefinite parking:** ten surfacings without an owner word;
  N6 is the epilogue's terminal gate, so the ELEVENTH surfacing is the last
  natural forcing function in the funded scope. Mitigation: Condition 5's
  terminal-gate note + the post-epilogue parking posture recorded, never a
  silent drop.

   Linux precedent has an Xvfb + software-renderer smoke; a macOS analog

   launched-verified. Optional — if not taken, the named non-verification
   stands honestly, and the N5 exit gate may revisit.
