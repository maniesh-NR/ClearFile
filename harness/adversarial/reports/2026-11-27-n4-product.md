## Risks register

- **The CI-only C++ round-count (the named cost, Condition 4):** zero
  local lane (measured — no mingw/MSVC/clang; host g++ cannot compile
  Win32/D2D; no cmake/ninja), so every compile/link error is a
  blind push→wait→inspect round; the MSVC-specific classes are new (the
  .dll import-lib link, UTF-16/wide-char marshaling, console codepage,
  the RC/version resource). Mitigations: the headless-first checkpoint,
  Condition 4's honest round logging, Condition 2(i)'s expected-text
  line-ending ruling, the red-close absorption rule.
- **The unguarded-header linkage class:** an unwrapped `#include` in the
  C++ TU = mangled symbols = a "first C++ consumer" that cannot link while
  the records claim it. Mitigation: Condition 3's recorded ruling.
- **Expected-text drift on Windows:** locale/decimal formatting, console
  codepage, and CRLF normalization against the committed expected text —
  the classic Windows CI flake family. Mitigation: Condition 2(i)'s
  ruling (raw engine emissions, pinned line endings/encoding).
- **The authored-but-unverified window mode:** the D2D rendering path is
  unproven (no interactive session); silent-wrong classes include the
  D2D factory failing in a service session and the palette's ARGB
  uint32 misread into D2D's RGBA ColorF (the classic silent-wrong-color
  byte-order bug). Mitigation: Condition 2(ii)'s named non-verification +
  Advisory 2 (the headless theme dump pins the color VALUES even though
  the rendering stays unverified).
- **The .dll load path in the headless smoke** (PATH vs
  copy-next-to-the-exe) — the Windows cousin of N3's fixture-path round.
  Mitigation: the ENG lane's wiring; named here because it is the most
  likely round-burner.
- **Runner image drift:** `windows-latest` is a floating label — the MSVC
  toolset/Windows SDK moves under the lane (the same live-verification
  discipline N5's list encodes for macOS). Mitigation: Advisory 4 (pin
  the runner identity in the lane record).
- **The slip's indefinite parking:** seven surfacings without an owner
  word; the proof of the pattern would be a cycle without the item.
  Mitigation: Condition 5's pinned enumeration + the gate-record agenda
  requirement.
- **The disk trend:** 1.8 GB (N3 entry) → 1.6 GB (this gate) → the
  in-sandbox sessions still cost bytes (target dirs, cargo caches); the
  CI-primary Windows box fetches nothing, but the per-session re-measure
  must continue (ENG's plan) so a mid-session ENOSPC is a logged slip,
  never a silent one.
