## The USA container format — COMPLETE (byte-proven end-to-end)

Extends `2026-11-22-tt-t2-reader.md`. Grammar (every clause below validated
against `TT_Personal_USA_2026.exe`; the walk also runs clean on
`TT_Business_USA_2026.exe`):

1. `0x99000` magic `48 12 90 BF 49 FF 91 AA`; `0x99008` internal header
   (`u32=1`, `u16=0x0200`: name-encryption OFF, selector 0x100); `0x9900e`
   name/value map (`[u16 len][blob]` pairs, `[u16 0]` terminates);
   `0x99200` entries.
2. **Entry header** (T2 session 1's table, fields A/B now resolved):
   `[u32 magic 0x6d27e59b][u8 type: 1=dir, 2=file, 0=end][u16 namelen]
   [name][u64 local FILETIME][u32 attributes (A)][u32 first-chunk csize (B)]`.
   - **A = Win32 file-attributes bitmask** (from FUN_00418c60's full
     decompile: `A & 2` selects an alternate create path; post-extraction
     `A != 0x20` triggers the set-attributes call FUN_0041c500; 0x20 =
     FILE_ATTRIBUTE_ARCHIVE, the observed no-op default).
   - **B = the FIRST deflate chunk's compressed size** (the stream at
     +0x20 self-terminates at exactly B bytes: out=90,000, eof=True,
     consumed=B byte-proven).
3. **Payload grammar (the D36 chunked layout):**
   `[deflate stream, B bytes] ([u32 csize < 0x80000000][csize B raw
   Deflate] | [u32 0x80000000|size][size B stored raw])* [u32 0]` then the
   next entry. Each deflate chunk is a SEPARATE self-terminating raw
   Deflate stream (zlib `wbits=-15`); the 0x80000000 flag word = STORED
   mode (raw copy, size = value & 0x7fffffff). Observed output granularities:
   90,000 B for the small-file chunks; exactly 1 MiB for the big-file
   deflate chunks and the stored segments.
4. **End of archive:** an entry with `type = 0` (magic + type + namelen 0)
   — FUN_00418c60's `type 0 → "Found end of archive"` path; observed at
   0x18141f55 (Personal-USA).
5. **Trailing signature:** ~10 KB after the end-entry = a DER PKCS#7
   SignedData blob (OID 1.2.840.113549.1.7.2; SHA-384 + Microsoft OIDs at
   identifier level; high-entropy certificates) — the SFX writer signs the
   container. Existence recorded only.
